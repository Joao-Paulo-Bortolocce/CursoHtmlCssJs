Projeto 1 · Cartão pessoal

Perfil de usuário com redes sociais e ícones

Este projeto usa HTML semântico para estruturar o perfil, CSS para a composição visual e SVG inline para os ícones. A capa em gradiente, o avatar sobreposto e as estatísticas mostram como combinar box model, tipografia e Flexbox em um componente coeso.

Projeto 2 · Mídia incorporada

Mini-galeria de vídeos com navegação por links

A galeria usa um único iframe nomeado e links com target apontando para esse nome. Cada miniatura carrega uma URL de embed do YouTube. Ao clicar, o vídeo é trocado dentro do mesmo frame, sem recarregar a página.

Clique nas miniaturas para trocar o vídeo dentro do iframe nomeado.

Visualização local: o YouTube pode exibir o erro 153 quando a página é aberta via file://. Sirva a pasta com um servidor HTTP, como python -m http.server, e acesse http://localhost:8000 para testar a troca de vídeos.

Privacidade: vídeos incorporados podem definir cookies e coletar dados. Considere o modo de privacidade do YouTube e informe o visitante quando necessário.

Projeto 3 · Identidade visual

Mini-site responsivo com mascote e variáveis CSS

Este mini-site simula uma página institucional com um mascote estilo Android. As variáveis em :root centralizam a paleta, o raio e o espaçamento. A tipografia combina Bebas Neue, Work Sans e Kaushan Script. O layout usa Grid fluido com auto-fit e minmax(), além de clamp() para escalar títulos sem media queries em cada detalhe.

Projeto 4 · Profundidade

Parallax simples com background-attachment: fixed

O efeito parallax acontece quando o fundo de uma seção permanece fixo enquanto o conteúdo rola. A técnica mais simples usa background-attachment: fixed, background-size: cover e uma camada de gradiente para garantir contraste. Intercale seções de imagem com blocos de texto para criar ritmo.

Resultado renderizado role a página

Respire.

O fundo permanece enquanto o texto avança.

Conteúdo em primeiro lugar

O parallax é um detalhe visual. O texto continua legível, com contraste suficiente e sem depender do movimento.

Continue.

A imagem de fundo fica presa à viewport.

Desempenho e acessibilidade: background-attachment: fixed pode causar problemas em celulares e sofrer com prefers-reduced-motion. Desative em telas pequenas e ofereça uma versão estática.

Fim da trilha

Desafio final: combine tudo

Você percorreu os fundamentos do HTML, a apresentação com CSS, o box model, tabelas, formulários, responsividade, Flexbox e projetos. O próximo passo é construir sem copiar: escolha um tema, defina um design system com variáveis e implemente uma página completa.

Estrutura

Use landmarks, títulos em ordem, listas, tabelas e formulários acessíveis.

Estilo

Crie tokens de cor, tipografia e espaçamento. Documente as decisões.

Adaptação

Comece mobile-first, teste teclado, zoom, orientação e impressão.

Projeto sugerido: construa um mini-portfólio com perfil, galeria de projetos, formulário de contato, menu responsivo, cards em Flexbox/Grid e uma seção com fundo parallax. Publique e peça feedback.
