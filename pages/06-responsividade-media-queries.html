Módulo 06 · Adaptação

Responsividade e media queries

Um layout responsivo não é um layout “para celular” separado: é o mesmo conteúdo se adaptando ao espaço disponível. Aqui você parte da tela menor, define breakpoints com intenção e constrói componentes flexíveis.

  • Nível intermediário
  • 5 tópicos práticos
  • Leitura estimada: 35 min
01

Comece pelo essencial

Abordagem mobile-first e viewport

Mobile-first significa escrever primeiro o estilo necessário para telas pequenas e depois adicionar melhorias com min-width. Essa abordagem prioriza conteúdo, desempenho e simplicidade. A tag de viewport é indispensável: sem ela, o celular simula uma tela larga e reduz tudo, prejudicando a leitura e o toque.

Resultado renderizado redimensione
Faixa atual: base · menos de 480px ≥ 480px · mobile amplo ≥ 768px · tablet ≥ 1024px · desktop ≥ 1440px · tela ampla

Conteúdo primeiro

A base funciona em uma coluna, sem depender de largura.

Melhoria progressiva

As colunas extras aparecem quando há espaço suficiente.

Leitura confortável

Espaçamento e tamanho de fonte acompanham o contexto.

Não comece pelo desktop: escrever primeiro para telas grandes costuma gerar regras de “desfazer” e layouts frágeis. A base mobile mantém o foco no conteúdo essencial.

02

Contexto de uso

@media screen, print e orientation

Media queries não servem apenas para largura. O tipo de mídia screen representa telas; print representa a impressão. A característica orientation distingue retrato e paisagem. Também é possível combinar condições com and e vírgulas, que funcionam como “ou”.

Impressão: teste com a pré-visualização de impressão. Esconda navegação, botões e elementos decorativos, e garanta que links e conteúdo essencial continuem legíveis.

03

Pontos de mudança

Breakpoints para tablet, desktop e telas amplas

Breakpoints são larguras em que o layout precisa mudar para continuar legível. Não existe uma lista universal: observe o conteúdo e escolha pontos em que ele quebra. Uma progressão comum é 480px, 768px, 1024px e 1440px. Use min-width para mobile-first e combine com características como min-resolution para telas de alta densidade.

Resultado renderizado redimensione
Breakpoint ativo: base 480px 768px 1024px 1440px

480px

Mais respiro horizontal e tipografia um pouco maior.

768px

Duas colunas para conteúdo e componentes lado a lado.

1024px

Três colunas e navegação expandida.

1440px

Container com largura máxima para evitar linhas longas.

Breakpoints por conteúdo: redimensione devagar e observe onde o texto fica apertado, as imagens cortam ou os botões quebram. Esse é o ponto real de mudança, não um número de dispositivo específico.

04

Mídia que acompanha o espaço

Imagens fluidas e componentes adaptativos

A regra base é max-width: 100%; height: auto;. Ela impede que a imagem ultrapasse o contêiner e preserva a proporção. Para oferecer resoluções diferentes, use srcset e sizes. Componentes adaptativos combinam essas imagens com grids que mudam de uma para duas colunas conforme o espaço.

Resultado renderizado redimensione

Componente adaptativo

Em telas pequenas, a imagem fica acima do texto. A partir de 700px, ela passa para a esquerda com largura fixa e o texto ocupa o espaço restante. O mesmo HTML se reorganiza com CSS.

A imagem é fluida e o componente muda de coluna conforme a largura.

Proporção: informe width e height no HTML para reservar espaço e evitar saltos de layout. O CSS com height:auto preserva a proporção.

05

Componente adaptativo

Menu hambúrguer com CSS puro

Um menu hambúrguer economiza espaço em telas pequenas. Podemos criar uma versão funcional sem JavaScript usando um checkbox oculto e um label que o alterna. O seletor :checked revela a lista de links. Em telas maiores, a media query esconde o botão e exibe a navegação completa.

Para uma experiência de acessibilidade mais robusta, adicione JavaScript para atualizar aria-expanded e gerenciar o foco. A versão com CSS já funciona por teclado e clique, mas não anuncia o estado aberto/fechado a todos os leitores de tela.

Resultado renderizado interativo
Início Breakpoints Imagens Contato

Em telas menores que 640px, clique em “Menu” para abrir os links. Em telas maiores, a navegação fica sempre visível.

Teste de toque: alvos interativos devem ter pelo menos cerca de 44 × 44 px. O label do menu precisa ser fácil de acertar com o dedo.

✓

Fechamento

Uma interface, muitos contextos

Você adotou a mentalidade mobile-first, usou media queries para tela, impressão e orientação, estruturou breakpoints, aplicou imagens fluidas e construiu um menu adaptativo com CSS.

Exercício: crie uma página de produto com uma grade de 1, 2 e 3 colunas, uma imagem fluida com srcset, uma versão de impressão sem menus e um menu hambúrguer funcional em telas pequenas.
