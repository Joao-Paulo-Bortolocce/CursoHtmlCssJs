Módulo 01 · Estrutura e conteúdo

Fundamentos de HTML

HTML é a linguagem de marcação que descreve a estrutura e o significado do conteúdo de uma página. Neste módulo, você constrói documentos válidos, organiza textos, conecta páginas e incorpora imagens, áudio e vídeo.

01

Ponto de partida

O esqueleto de um documento HTML5

Todo documento começa com <!DOCTYPE html>, que ativa o modo de renderização moderno do navegador. O elemento <html> envolve todo o conteúdo e recebe o atributo lang para indicar o idioma principal — uma informação essencial para leitores de tela, tradutores e mecanismos de busca.

O <head> guarda metadados invisíveis: codificação, viewport, descrição e título. O <body> contém tudo o que o visitante vê. A declaração charset="UTF-8" permite acentos e símbolos corretamente; o viewport faz a página se adaptar à largura do dispositivo.

Dica de professor: use sempre lang="pt-BR" em páginas em português do Brasil. O atributo não muda a aparência, mas melhora pronúncia, tradução e indexação.

02

Fluxo de texto

Espaços, quebras de linha e separadores

O HTML reduz sequências de espaços, tabulações e quebras de linha a um único espaço visual. Portanto, apertar Enter várias vezes no código não cria parágrafos. Para iniciar um novo parágrafo, use <p>; para uma quebra dentro do mesmo bloco, use <br>; para uma linha divisória temática, use <hr>.

Resultado renderizado ao vivo

O <hr> cria uma separação temática entre assuntos.

Cuidado: <br> serve para quebras de linha reais (poemas, endereços, letras de música), não para criar espaço entre elementos. Para espaçamento visual, use CSS.

03

Caracteres especiais

Entidades HTML e emojis por código

Alguns caracteres têm significado especial no HTML, como < e &. Para exibi-los literalmente, use entidades. Elas também representam símbolos que talvez não existam no teclado: &reg; (marca registrada), &copy; (copyright), &euro; (euro), &nbsp; (espaço não separável) e muitas outras.

Emojis podem ser inseridos diretamente no documento ou por seu código hexadecimal Unicode, no formato &#x1F680;. O prefixo x indica base hexadecimal. Isso é útil quando o editor não oferece o caractere visual.

04

Organização lógica

Hierarquia de títulos: h1 a h6

Os títulos criam um sumário navegável para leitores de tela e mecanismos de busca. Use um único <h1> por página para o assunto principal e distribua os demais níveis em ordem lógica, sem pular etapas apenas por preferência visual. O tamanho padrão pode ser alterado com CSS; a escolha do nível deve ser semântica.

05

Significado antes da aparência

Semântica textual avançada

Muitos elementos parecem visualmente iguais, mas carregam significados diferentes. <strong> indica importância; <em> indica ênfase; <mark> destaca uma passagem relevante; <del> e <ins> registram remoções e inserções. Use cada um pelo significado, não apenas pelo estilo padrão.

Para trechos de código, use <code>. Se precisar preservar espaços e quebras, combine com <pre>. Citações curtas usam <q>; citações longas usam <blockquote> com o atributo cite. Abreviações ganham contexto com <abbr title>.

06

Sequências e coleções

Listas ordenadas, não ordenadas e de definição

Use <ol> quando a ordem importa: passos, rankings, instruções. O atributo type escolhe a numeração (1, A, a, I, i) e start define o valor inicial. Para coleções sem ordem, use <ul>. Já <dl> associa termos (<dt>) a definições (<dd>).

07

A Web é feita de conexões

Links absolutos, relativos e downloads

O elemento <a> cria hiperlinks. Um caminho absoluto inclui o protocolo e o domínio; um caminho relativo aponta para outro arquivo do mesmo projeto. Use target="_blank" para abrir em nova aba e, por segurança, acompanhe com rel="noopener noreferrer". Links externos podem receber rel="external nofollow" para sinalizar que não são do site.

O atributo download sugere o download em vez da navegação. O atributo type informa o tipo do arquivo, e href aponta para o recurso. Para âncoras internas, o destino é o id de um elemento.

08

Conteúdo visual

Imagens estáticas e imagens adaptativas

Toda imagem informativa precisa de alt descrevendo seu conteúdo. Imagens puramente decorativas podem usar alt="" para serem ignoradas por leitores de tela. Informar width e height ajuda o navegador a reservar espaço e reduzir o deslocamento de layout.

O elemento <picture> permite oferecer versões diferentes da mesma imagem. O navegador escolhe a primeira <source> compatível com a mídia e o formato. A <img> final é obrigatória e funciona como fallback. Coloque as condições mais específicas primeiro.

09

Mídia nativa

Áudio, vídeo e incorporação de terceiros

<audio> e <video> incorporam mídia sem plugins. O atributo controls exibe os controles nativos; preload orienta o carregamento; loop repete a reprodução. Para vídeo, poster define a imagem exibida antes do play. Ofereça múltiplos <source> para fallback de formato e um texto dentro do elemento para navegadores sem suporte.

O <iframe> incorpora outro documento. Ele é comum para mapas, players e widgets. Sempre inclua title descritivo e restrinja permissões com allow quando possível. allowfullscreen autoriza a tela cheia do player.
