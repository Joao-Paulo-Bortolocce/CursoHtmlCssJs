Módulo 02 · Apresentação visual

Fundamentos de CSS

CSS (Cascading Style Sheets) controla a apresentação do documento. Neste módulo, você aplica estilos de três maneiras, escolhe cores com diferentes modelos, cria gradientes, domina tipografia e seleciona elementos com precisão.

  • Nível iniciante
  • 7 tópicos práticos
  • Leitura estimada: 40 min
01

Três caminhos

Inline, interno e externo

CSS pode ser aplicado diretamente no elemento com o atributo style, em um bloco <style> dentro do <head> ou em um arquivo .css separado conectado com <link>. A folha externa é a opção mais sustentável: centraliza o estilo, permite cache e mantém o HTML limpo.

Boa prática: prefira a folha externa. Reserve o CSS interno para páginas realmente isoladas e o inline para ajustes dinâmicos ou protótipos rápidos.

02

Cor e contraste

Nomes, hexadecimal, rgb() e hsl()

O CSS aceita nomes de cor (tomato, navy), hexadecimal (#4f46e5), RGB (rgb(79 70 229)) e HSL (hsl(243 75% 59%)). RGB e HSL também aceitam transparência com o quarto valor. HSL é especialmente útil para criar variações de matiz, saturação e luminosidade sem decorar códigos.

Atenção ao contraste: cor não deve ser o único meio de transmitir informação. Erros, estados e links precisam de texto ou ícones complementares.

03

Profundidade visual

Gradientes lineares, radiais e fundos fixos

Gradientes são imagens geradas pelo navegador. linear-gradient() transita entre cores ao longo de uma direção; radial-gradient() parte de um ponto. Eles podem ser combinados com imagens usando camadas: a primeira camada fica na frente. background-size: cover cobre toda a área, enquanto contain garante que a imagem inteira apareça.

background-attachment: fixed fixa o fundo em relação à viewport, criando um efeito de profundidade ao rolar a página. Use com moderação e desative em telas pequenas por questões de desempenho.

04

Leitura e personalidade

Pilhas de fontes, unidades e alinhamento

A propriedade font-family recebe uma pilha: o navegador tenta a primeira fonte e segue para as próximas se disponíveis. Sempre termine com uma família genérica (sans-serif, serif, monospace). Use rem para tamanhos globais previsíveis e em para escalas relativas ao contexto local.

text-align alinha o texto; text-indent recua a primeira linha; line-height controla o espaçamento vertical entre linhas. Fontes externas podem ser carregadas com uma tag <link> (recomendado) ou com @import no início do CSS.

Recuo de primeira linha

A propriedade text-indent desloca apenas a primeira linha do parágrafo. Esse recurso é comum em textos literários e em composições editoriais que desejam marcar visualmente o início de cada bloco de leitura. Use com equilíbrio e sempre verifique a legibilidade em telas pequenas.

Desempenho: carregue apenas os pesos e estilos realmente usados. Fontes externas são recursos de rede e impactam o primeiro carregamento.

05

Encontrar o alvo certo

Seletores, classes, IDs e combinadores

Seletores determinam quais elementos recebem uma regra. IDs usam #, classes usam ., o seletor universal * atinge todos os elementos, e o agrupamento separa seletores por vírgula. O combinador > atinge apenas filhos diretos. Essas ferramentas permitem criar estilos reutilizáveis sem repetir código.

  • Terceiro item — regras agrupadas mantêm a consistência.

06

Estados e partes do elemento

:hover, :active, :visited, ::before e ::after

Pseudo-classes selecionam um estado ou posição do elemento. As mais comuns em links são :hover (ponteiro sobre o elemento), :active (enquanto pressionado) e :visited (link já visitado). Pseudo-elementos criam partes estilizáveis que não existem no HTML, como ::before e ::after. Eles exigem a propriedade content, mesmo que receba uma string vazia.

07

Quem vence a disputa?

Especificidade e cascata

Quando duas regras conflitam, o navegador calcula a especificidade. A ordem de força é: estilos inline, IDs, classes/atributos/pseudo-classes e tipos/pseudo-elementos. O seletor universal não soma pontos. Em caso de empate, vence a regra declarada por último. !important deve ser evitado, pois rompe a cascata e dificulta a manutenção.

Resultado renderizado ao vivo

Seletor de tipo: p { color: #64748b; }

Seletor de classe: .texto-especial { color: #0f766e; }

Seletor de ID vence: #mensagem-principal { color: #4f46e5; }

Como calcular a especificidade (inline, IDs, classes, tipos)
Seletor Especificidade Quem vence?
* (0, 0, 0, 0) Menor prioridade
p (0, 0, 0, 1) Tipo
.card (0, 0, 1, 0) Classe
#menu (0, 1, 0, 0) ID
style="..." (1, 0, 0, 0) Inline

Estratégia recomendada: estilize principalmente por classes. IDs são melhores para âncoras e referências únicas; estilos inline ficam para exceções.
